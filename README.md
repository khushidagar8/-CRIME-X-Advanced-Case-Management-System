# 🔍 CRIME-X – Advanced Case Management System

**CRIME-X** is a Python-based Advanced Crime Case Management System designed to manage and organize crime investigation records through a professional graphical user interface (GUI).

The system helps users add, view, search, update, and manage case records efficiently.

## 🚀 Features

- 📊 Professional Dashboard
- ➕ Add New Case
- 🔎 Search Case Records
- 👁️ View Complete Case Details
- ✏️ Edit Existing Cases
- 🗂️ Case Management System
- 📈 Total Cases Counter
- 🔄 Open Cases Tracking
- 🕵️ Under Investigation Tracking
- ✅ Closed Cases Tracking
- 🗑️ Delete Case Functionality

## 🛠️ Technologies Used

- Python
- Tkinter (GUI Development)
- Database Management
- Python Libraries

## 💻 Application Interface

CRIME-X provides a clean and user-friendly dashboard for managing investigation records and monitoring case statuses.

## 🎯 Project Objective

The main objective of CRIME-X is to simplify crime case record management, improve organization, and provide an easy-to-use digital platform for tracking investigation cases.

## ⚙️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open the main Python file in Python IDLE.
4. Press F5 or select Run → Run Module.
5. The CRIME-X application will launch.
